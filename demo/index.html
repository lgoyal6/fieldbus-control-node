Why the watchdog uses accepted frames

Bad data cannot keep the controller alive.

01

Validate

The core checks the frame identifier, length, sequence, reserved bytes, value range, and CRC.

02

Feed on acceptance

Only a trusted sensor frame refreshes the watchdog timer. A rejected frame does not.

03

Latch safe

When no trusted frame arrives within the timeout, the node commands the safe actuator value and stays latched.
